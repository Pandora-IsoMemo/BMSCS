# prepareData

prepareData

## Usage

``` r
prepareData(
  rawData,
  in_x,
  in_xUnc,
  in_y,
  in_yUnc,
  in_xCategorical,
  in_xCatUnc,
  in_regType
)
```

## Arguments

- rawData:

  (reactive) data()

- in_x:

  (reactive) input\$x

- in_xUnc:

  (reactive) input\$xUnc

- in_y:

  (reactive) input\$y

- in_yUnc:

  (reactive) input\$yUnc

- in_xCategorical:

  (reactive) input\$xCategorical

- in_xCatUnc:

  (reactive) input\$xCatUnc

- in_regType:

  (reactive) input\$regType
