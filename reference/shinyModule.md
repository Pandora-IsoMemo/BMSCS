# Server and UI Functions for Shiny Module

Server and UI Functions for Shiny Module

## Usage

``` r
dataInputUI(id, title = "")

dataInput(input, output, session)

modelEstimationUI(id, title = "")

modelEstimation(input, output, session, data)
```

## Arguments

- id:

  namespace id

- title:

  title of tab in tabset panel

- input:

  shiny input object

- output:

  shiny output object

- session:

  shiny session

- data:

  data reactive
